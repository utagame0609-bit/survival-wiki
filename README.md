# Survival Wiki — Legacy

このリポジトリは旧 Survival Wiki の履歴保存用です。

現在は開発を終了しており、今後の機能追加・公開・運用には使用しません。

現行プロダクトは `savepoint-app` です。

旧 Survival Wiki で使用していた Supabase 基盤は、Savepoint 用バックエンドとして再利用するため保持されています。旧テーブル・Storage・Edge Function は Legacy として残しており、現行 Savepoint へはまだ接続していません。

このリポジトリを再利用・再デプロイする場合は、Savepoint 側の現行構成と衝突しないかを先に確認してください。
